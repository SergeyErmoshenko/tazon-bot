# Установка на Windows-ноутбук

## 1. Python

1. Скачай Python 3.12+ с [python.org](https://www.python.org/downloads/) (или из Microsoft Store).
2. При установке **обязательно** поставь галочку **"Add python.exe to PATH"**.
3. Проверь в cmd: `python --version` → должно показать 3.12+.

## 2. Проект

Раскатай папку проекта, например в `C:\tazon-bot`. В cmd:

```bat
cd C:\tazon-bot
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\playwright.exe install chromium
```

(Playwright скачает свой Chromium ~150 МБ — это нормально.)

## 3. Токен бота и chat_id

1. В Telegram у [@BotFather](https://t.me/BotFather): `/newbot` → получишь токен вида `123456:AA...`.
2. Узнай свой числовой id у [@userinfobot](https://t.me/userinfobot).
3. Скопируй `.env.example` → `.env` и впиши `BOT_TOKEN` и `ADMIN_CHAT_ID`.
   (Бот будет отвечать только тебе — никто чужой им не воспользуется.)

## 4. Первый запуск и проверка парсера

```bat
scripts\start.bat
```

В Telegram у бота: `/start` → кинуть ссылку на любой товар Ozon → бот должен ответить ценой.

Если цена не читается, проверь парсер напрямую на живой карточке:

```bat
.venv\Scripts\python.exe -m bot.ozon_check "https://www.ozon.ru/product/xxxxxxx/"
```

- `ok: True` и цены на месте — всё работает;
- `blocked: True` — антибот: проверь, не заворачивает ли весь трафик VPN/прокси-клиент
  (при TUN-режимах Ozon бывает недоступен);
- `error` с таймаутом — проверь интернет/прокси.

Как устроен обход антибота: Chrome запускается обычным приложением (без флагов
автоматизации — их Ozon детектит и отвечает 403), а бот подключается к нему по
протоколу отладки (CDP). Профиль браузера хранится в `data\browser-profile\`
(сеян копией твоего рабочего профиля — «тёплые» куки помогают проходить челленджи).

Приложи вывод этой команды, если будешь просить помочь с починкой селекторов.

## 5. Автозапуск при включении ноутбука

Задача планировщика уже создана (имя `tazon-bot`, запуск при входе в систему).
Проверить/пересоздать руками:

```bat
schtasks /create /tn tazon-bot /tr C:\Users\1\tazon-bot\scripts\start.bat /sc onlogon /rl limited /f
schtasks /run /tn tazon-bot
```

Через GUI (Win+R → `taskschd.msc`): «Создать простую задачу» → имя `tazon-bot` →
триггер **«При входе в систему»** → программа `…\scripts\start.bat`; в свойствах
сними «Остановить задачу, если она выполняется дольше 3 дней» и включи
«При сбое перезапускать через 1 минуту».
4. В свойствах задачи (правый клик → Свойства):
   - «Общие»: галка «Выполнять вне зависимости от регистрации пользователя» не нужна —
     хватит запуска при входе; поставь «Выполнять с наивысшими правами», если UCC ругается;
   - «Параметры»: снимите «Остановить задачу, если она выполняется дольше 3 дней»
     (задача должна жить постоянно);
   - «Параметры»: «При сбое перезапускать через 1 минуту».

Проще всего — включить автовход в систему, тогда ноутбук после включения сам
поднимет бота.

## 6. Питание (важно!)

Пока ноутбук спит — проверок нет. В «Электропитании»:
- «Сон»: **Никогда** (экран можно гасить, это не мешает);
- при питании от батареи тоже (или держи на зарядке).

Пропущенные проверки не страшны: история просто продолжится со следующего
успешного прогона.

## 7. Обновление

Замени файлы проекта и перезапусти (или перезапусти задачу в Планировщике).
Если добавились зависимости — снова `.venv\Scripts\pip install -r requirements.txt`.

## Куда пишутся данные

- `data\monitor.db` — база товаров и истории цен;
- `data\browser-profile\` — профиль браузера (куки антибота — **не удаляй**,
  с ним меньше блокировок);
- `logs\bot.log` — журнал.
