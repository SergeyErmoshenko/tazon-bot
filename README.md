# tazon-bot — мониторинг цен на Ozon

Telegram-бот для личного использования: следит за ценами выбранных товаров на Ozon,
присылает уведомления при снижении и рисует график истории.

## Как работает

- Кидаешь боту ссылку на товар (любой вид — с tracking-хвостами, из шаринга) →
  он добавляется в список и сразу показывает цену.
- Несколько раз в день (по расписанию, по умолчанию 08:00/14:00/20:00/02:00 + случайное
  смещение) бот обходит карточки в реальном Chrome и пишет точку в SQLite.
- Отслеживается **одна цена — минимальная** («с Ozon Картой» / «С банками»).
  Зачёркнутые старые цены и «638 ₽ за 1 шт» (цена за единицу в наборах)
  отфильтровываются по DOM-стилям и подписям.
- Если минимальная цена снизилась — уведомление: старая → новая, −X ₽ и −Y%, ссылка.
- `/list` → кнопки, кнопка присылает PNG-график истории.

Почему так: официального API для чужих цен нет, внутренние API Ozon закрыты антиботом
(403 «Antibot Challenge»), а Chrome, запущенный самим Playwright/Selenium, детектится
по флагам запуска. Схема, которая проходит: Chrome стартует как **обычное приложение**
(только порт отладки + постоянный профиль), бот подключается к нему по CDP. Вся логика
чтения страницы — в `bot/ozon.py` (если Ozon поменяет вёрстку — чинить там).

## Команды

| Команда | Что делает |
|---|---|
| ссылка на товар | добавить товар, показать текущую цену |
| `/list` | список товаров + кнопки с графиками |
| `/check` | проверить все товары прямо сейчас |
| `/del` | удалить товар |
| `/help` | справка |

Диагностика парсера без бота: `python -m bot.ozon_check "<url>"`.

## Установка и запуск

На Windows — см. [scripts/INSTALL.md](scripts/INSTALL.md) (полная инструкция:
Python, venv, токен, автозапуск, питание). Коротко:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\playwright.exe install chromium
copy .env.example .env   :: вписать BOT_TOKEN и ADMIN_CHAT_ID
scripts\start.bat
```

## Тесты

```bat
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest tests -v
```

## Структура

```
bot/
  config.py     — настройки из .env (токен, расписание, headless)
  db.py         — SQLite: products, price_points
  ozon.py       — парсер цен (чистые функции + Playwright-обвязка)
  notifier.py   — детект снижения, тексты уведомлений
  charts.py     — график истории (matplotlib → PNG)
  runner.py     — прогон по всем товарам (для /check и расписания)
  scheduler.py  — APScheduler cron
  handlers.py   — Telegram-хендлеры (aiogram 3)
  main.py       — точка входа
  ozon_check.py — CLI-диагностика парсера
scripts/        — start.bat, INSTALL.md
tests/          — pytest: парсинг, детект снижений, БД
data/           — monitor.db, профиль браузера (создаётся само)
logs/           — bot.log
```

## Ограничения

- Селекторы цен привязаны к текущей вёрстке Ozon — при её смене бот пришлёт
  алерт «товар N прогонов не читается», починка — правка `bot/ozon.py`.
- Ноутбук спит → проверок нет (история продолжается после пробуждения).
- Толь­ко личное использование, низкая частота запросов (пауза 2–5 с между товарами) —
  так и задумано, не превращай в промышленный парсер.
