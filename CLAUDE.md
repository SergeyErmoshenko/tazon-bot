# tazon-bot — контекст проекта (для Claude Code)

Telegram-бот мониторинга цен на Ozon. Этот файл — выжимка всего опыта проекта,
читай его целиком перед любой работой здесь.

## Что это и для кого

Личный бот владельца: он кидает боту ссылки на любые товары Ozon (покупатель,
НЕ продавец — Seller API неприменим), бот несколько раз в день проверяет цены
и присылает уведомление при снижении, по кнопке — график истории.
- Бот: **@tazon_price_bot**, владелец chat_id **1425317618** (@Xelloww) — бот
  отвечает только ему (фильтр в `bot/handlers.py`).
- Отслеживается **одна цена — минимальная** («с Ozon Картой» / «С банками»):
  `card_price if not None else price` (см. `bot/notifier.py:effective_price`).
  Это осознанное требование владельца — не «улучшать» без спроса.
- Расписание: 8 раз в день (каждые 3 часа, `.env` → `CHECK_TIMES`).

## Ключевой антибот-опыт (самое ценное, добыто экспериментами)

1. Официального API чужих цен нет; внутренние API Ozon (entrypoint-api.bx) — 403.
2. Браузер, запущенный Playwright/Selenium (любые stealth-патчи, real Chrome
   binary, скопированный профиль, headless или нет) — **детектится** антиботом
   Ozon (система `fab_chlg`): «Похоже, нет соединения» / 403 Antibot Challenge.
   Причина — ~20 служебных флагов запуска, которые добавляет драйвер.
3. Рабочая схема (`bot/ozon.py`): Chrome стартует как **обычный subprocess**
   (`--remote-debugging-port=9222 --user-data-dir=... --start-minimized`),
   Playwright подключается `connect_over_cdp`. Работает даже в session 0 по SSH.
4. 403 + title «Antibot Challenge Page» ≠ блок: челлендж проходится сам и
   страница рендерится. Признак блока — только отсутствие цен после ~20 с.
5. Цены Ozon персонализированы: цифры у владельца и у бота отличаются на
   единицы процентов (динамика/сегменты). Это норма: бот — «один посетитель»,
   его ряд консистентен, снижения реальные. Не гоняться за цифрами из приложения.

## Как устроено распознавание цены (`bot/ozon.py`)

Порядок цен в виджете `[data-widget='webPrice']` стабилен:
`[карточная «С банками», обычная, старая зачёркнутая, «за 1 шт»]`.
- Основной путь: JS в странице (`_PRICE_DOM_JS`) собирает текстовые узлы с
  `число…₽`, отбрасывает «цены за единицу» (`₽ за 1 шт/уп/кг…`) и помеченные
  зачёркиванием (ненадёжно — Ozon рисует линию не text-decoration).
- Правило: первые две цены, если вторая больше → (обычная, карточная);
  остальное игнорируется. Текстовый фолбэк — тот же порядок; последний фолбэк —
  регэкспы по JSON в HTML (`PRICE_JSON_PATTERNS`).
- Название товара (`h1`) рендерится позже цен: `_product_title` ждёт до 12 с,
  при добавлении — вторая целевая попытка `fetch_title` (гарантия владельца:
  название в ответе сразу).
- Диагностика: `python -m bot.ozon_check "<url>"` (быстрая проверка парсера),
  `python scripts\debug_price.py "<url>"` (полный дамп виджета цен),
  `python scripts\fix_title.py` (добрать отсутствующие названия).

## Особенности окружения и грабли

- Ноутбук за SnowVPN (TUN/прокси-режимы, локальный порт 7897). Оба режима
  проверены — ozon доступен боту. Если владелец переключает режимы и бот
  начинает фейлиться — проверить `curl -I https://www.ozon.ru/` с ноута.
- Консоль Windows через SSH коверкает кириллицу: использовать
  `chcp 65001` + `python -X utf8`, многострочные вставки в PS 5.1 рвутся —
  команды давать по одной строке.
- PowerShell 5.1 `Invoke-WebRequest` падает на TLS (api.telegram.org) —
  брать curl. `wmic` выпилен — использовать PowerShell-аналоги.
- RDP-сессия владельца на ноуте: окна Chrome при проверках мелькают свёрнутыми —
  это норма, не закрывать их руками.
- У владельца: MacBook (рабочая машина, песочница tclaude) + этот Windows-ноут.
  Firefox и js-прокси владельца — вне зоны бота, не трогать без спроса.

## Правила, заданные владельцем (соблюдать)

- Уведомления и график — только по минимальной (карточной) цене.
- Название товара — сразу в ответе на добавление, не «при следующей проверке».
- `/del <ссылка>` — удаление по ссылке; `/del` — список с полными названиями
  (до 120 символов) и ссылками; кнопки — с номерами строк (лимит TG 64 симв.).
- Разные цвета/варианты товара = разные sku = отдельные товары (так и надо).
- В `/list` показывать длинные названия (до 120 символов).
